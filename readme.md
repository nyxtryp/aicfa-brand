# AICFA

## AI for Digital Financial Assets

AICFA — специализированная система искусственного интеллекта для анализа цифровых финансовых активов (ЦФА), криптоактивов и связанных с ними рыночных данных.

Проект создаётся как узкоспециализированный ИИ-аналитик, ориентированный на цифровые финансовые активы и финансовые рынки.
