# AICFA

## AI for Digital Financial Assets

AICFA — специализированная система искусственного интеллекта для анализа цифровых финансовых активов (ЦФА), криптоактивов и связанных с ними рыночных данных.

Проект создаётся как узкоспециализированный ИИ-аналитик, ориентированный на цифровые финансовые активы и финансовые рынки.

## Timestamp

Для документа создана криптографическая временная фиксация OpenTimestamps.

Файл подтверждения:

`AICFA_Brand_Declaration_2026-09-28.pdf.ots`

OpenTimestamps позволяет независимо проверить, что зафиксированная версия файла существовала не позднее соответствующего момента времени.

## Как проверить самостоятельно

Любой человек может проверить доказательство независимо от автора проекта:

1. Откройте этот публичный GitHub-репозиторий.
2. Скачайте файл `AICFA_Brand_Declaration_2026-09-28.pdf`.
3. Скачайте соответствующий файл `AICFA_Brand_Declaration_2026-09-28.pdf.ots`.
4. Самостоятельно вычислите SHA-256 PDF и сравните его с указанным выше:
   `14c79d515ba4e842a19b84bc0b51d406a313547f908024aa428ce8f01c624244`.
5. Откройте официальный сервис OpenTimestamps: https://opentimestamps.org/
6. Используйте функцию проверки (Verify) и укажите PDF вместе с соответствующим `.ots`-файлом.
7. OpenTimestamps проверит криптографическое доказательство временной фиксации файла.

Для локальной проверки SHA-256 в Linux можно выполнить:

```bash
sha256sum AICFA_Brand_Declaration_2026-09-28.pdf
```

Результат должен совпасть с хэшем, указанным в этом README.

### Важно

Проверяется именно конкретный файл PDF. Если PDF был изменён после создания timestamp, его SHA-256 изменится, и соответствующий `.ots` больше не будет подтверждать изменённую версию.

Криптографическая временная фиксация подтверждает существование конкретной версии документа на соответствующий момент времени. Она не является государственной регистрацией товарного знака и не заменяет регистрацию товарного знака или иное предусмотренное законом средство правовой охраны.
